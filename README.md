## ✨ Features

- **Dark Glassmorphism Theme** — Deep navy base (`#080c14`) with purple/cyan gradient accents
- **Animated Particle Canvas** — Constellation-style floating particles in the hero section
- **Custom Cursor** — Glowing dot + lagging ring cursor (desktop only)
- **Loading Screen** — Branded intro loader with animated progress bar
- **Typewriter Effect** — Cycles through: *Aspiring Software Engineer → DSA Enthusiast → Full-Stack Developer → Problem Solver → Competitive Programmer*
- **Scroll-Reveal Animations** — Elements fade in on scroll using Intersection Observer
- **Animated Counters** — Stats (LeetCode problems, CGPA, projects) count up on scroll
- **Skill Bars** — Animated progress bars triggered on scroll
- **Active Nav Highlighting** — Navbar link highlights based on current section in view
- **Responsive Design** — Fully optimized for mobile, tablet & desktop
- **Working Contact Form** — Integrated with Formspree for real email delivery
- **SEO Optimized** — Meta tags, Open Graph, semantic HTML5
